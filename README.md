# WageWorkers

This is a LinkedIn-style job marketplace app tailored for daily wage workers and contractors. It helps bridge the gap between skilled/unskilled laborers and hiring contractors, supporting both Android and Web via React Native (Expo).

## 🔧 Built With

- React Native (Expo)
- Razorpay Integration
- Tab Navigation (Home, Jobs, Messages, Notifications, Profile)
- Cross-platform support (Web + Android)

## 💼 Features

- Contractor & Worker Profiles
- Job Posting + Job Searching
- In-app Messaging System
- Razorpay Payments (INR)
- Featured Workers Carousel
- Location Selector
- Document Upload System
- Notification System

## 🚀 Deployment Plans

- Firebase / Supabase for backend (TBD)
- Hosting via Vercel / Expo Web
- Future Admin Dashboard and Analytics
